# Primary references

Access date: 28 October 2026. The implementation and examples are original teaching material. The sources below support definitions and established modelling considerations; they do not validate a particular industrial project.

1. U.S. Energy Information Administration. [Measuring electricity](https://www.eia.gov/energyexplained/electricity/measuring-electricity.php). Energy and power units.
2. Python Software Foundation. [zoneinfo: IANA time zone support](https://docs.python.org/3/library/zoneinfo.html). Named timezones and ambiguous local times. The supplied programs require Python 3.9+ and timezone data.
3. National laboratory System Advisor Model documentation. [Battery Storage: Front of Meter](https://samrepo.nlr.gov/help/battery_storage_fom.html). Distinct battery energy, power and converter/efficiency inputs. This toolkit does not implement SAM.
4. U.S. Department of Energy, FEMP. [Measurement and Verification for Federal Energy Savings Performance Contracts](https://www.energy.gov/cmei/femp/measurement-and-verification-federal-energy-savings-performance-contracts). A jurisdiction-specific example of documented baselines and verification responsibilities, not a universal contract rule.
5. National Renewable Energy Laboratory. [PVWatts Version 5 Manual](https://pvwatts.nrel.gov/downloads/pvwattsv5.pdf). Legacy reference for DC system-size and PV input definitions. No default value or yield result from this manual is used in the synthetic data.

The tariff/RHD request fields specify evidence to collect. No current regulated rate, tax treatment or financing entitlement is asserted here.
